# 家事をする｜もっとよくみる

添付された kaisha-ni-iku-source-v12(3).zip をもとにした家事版です。
静的な Three.js サイト。外部 CDN なしで動作します。

- dist/index.html: メイン画面
- dist/models.js: 共通のエプロン姿の人物、丸い二節の腕、メダル
- dist/scenes.js: 家事の8つの立体アニメーション（各7.5秒）
- dist/content.js: 文章、リボン、ズーム座標
- dist/hotspots.js / reticles.js: 探索領域と発見済み表示
- dist/app.js: 元の体験進行、戻る、リセット、キーボード
- dist/experience.html: build-standalone.mjsで生成した単一HTML

## 操作
人物の花形の目印または身体・持ち物を選択。メダル後は余白、戻るボタン、Escapeで人物に戻ります。
キャンバスにフォーカスして矢印キーとEnter/Spaceでも探索できます。

## 検証
node checks.mjs
node flow-check.mjs
node verify-housework.mjs
node build-standalone.mjs

8つのレイキャスト、進行、文章、戻る、発見記録、リセット、キーボード、390x844/639x720/1920x1080の目印の投影を検証。
flow-checkはWebGLRendererとDOMを模した数値・状態検証です。ブラウザでの実クリック、GPU描画、見た目の最終確認は未実施です。

## 第2版の修正
- 袖を二つの球体から連続したテーパー形状に変更。
- エプロン本体を胸当てから裾・首ひもまで一続きのメッシュに変更。
- 袖の発見を「雨の前に洗濯物を取り込む」に変更。
- 冷蔵庫を空洞構造に変更し、扉の掃引範囲と人物の移動経路を分離。
- 全シーンで家具の配置・運搬経路を再調整。
- collision-audit.mjs は0.1秒間隔で頭・胴体・脚・靴と外部メッシュのワールドAABBを比較。各軸0.035を超える重なりを検出する限定的な数値確認で、全三角形の衝突保証や目視検証ではありません。

## 第4版
人物の回転を全軸で設定し、作業対象へ向けてから手の位置を再計算。facing-check.mjsで全8シーンの作業中の手が身体の前にあることを検証。ジオラマの見せる角度を変更。掃除中の仮置き場所を掃除機の待機位置と分離。下段キャプションを説明文に変更。
